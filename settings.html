美化 - UI主题自定义

在自定义CSS中添加标记注释，即可在面板中可视化修改图片、文字和颜色。

UI主题自定义面板位于 用户设置 → 主题颜色 上方。

注意：标记注释中的名称不能重复！不同标记项请使用不同的名称。
标记格式
图片 /* ggg-img: 名称 */
/* ggg-img-user: 名称 */
/* ggg-img-char: 名称 */
放在 url('...') 的前面（同一行或上一行均可）
文字 /* ggg-text: 名称 */
/* ggg-text-user: 名称 */
/* ggg-text-char: 名称 */
放在 content: "..." 的前面（同一行或上一行均可）
颜色 /* ggg-color: 名称 */
/* ggg-color-user: 名称 */
/* ggg-color-char: 名称 */
放在颜色值或CSS变量声明的前面（同一行或上一行均可）
尺寸 /* ggg-dim: 名称 */
/* ggg-dim-user: 名称 */
/* ggg-dim-char: 名称 */
放在CSS数值属性（如 top、width、height 等）的上一行
使用示例
以下示例美化代码来自呱呱
/* 图片标记 - 标记在上一行 */
#chat .mes .ch_name::before {
    /* ggg-img-char: 闪烁星星图 */
    background-image: url('https://i.postimg.cc/JzNHCLGK/1-1-1.png');
    background-size: auto 100%;
}

/* 图片标记 - 标记在同一行 */
#chat .mes .ch_name::after {
    background-image: /* ggg-img-user: 闪烁星星图*/url('https://i.postimg.cc/mk42wcSs/2-1-1.png');
}

/* 文字标记 */
.mes:not([is_user="true"])::before {
    /* ggg-text: 搜索框文字 */
    content: "crush约我吃日料但我海鲜过敏怎么办T T";
}

/* 颜色标记 - 标记在上一行（推荐） */
:root {
    /* ggg-color: 主题色 */
    --blur-tint-color: rgba(178, 152, 164, 1);
}

/* 颜色标记 - 标记在同一行 */
:root {
    --my-border: /* ggg-color-char: 角色边框色 */ #ff6b9d;
}

/* 尺寸标记 - 用于自定义位置和大小 */
.mes:not([is_user="true"]) .mesAvatarWrapper .mesIDDisplay::after {
    content: "";
    position: absolute;
    /* ggg-dim: 增大下移 */
    top: -45px;
    /* ggg-dim: 增大左移 */
    right: -30px;
    /* ggg-dim: 宽 */
    width: 70px;
    /* ggg-dim: 高 */
    height: 70px;
    /* ggg-img-char: 楼层背图 */
    background: url('https://i.postimg.cc/jqn88QPT/hui.png') no-repeat center;
    background-size: contain;
}

/* 歌词动画中的文字标记 */
@keyframes userLyrics {
    /* ggg-text-user: user歌词1 */
    0%, 14.6% { content: "You and I are a story"; }
    /* ggg-text-user: user歌词2 */
    14.7%, 30.3% { content: "That never gets told"; }
}
字体管理
功能位置 切换到「字体」标签页
字体管理支持导入本地字体文件和在线字体，并可设置使用范围和大小
导入文件 支持 ttf / otf / woff / woff2 格式
字体文件会上传到服务器，通过 @font-face 注入
导入在线 粘贴 @import url(...) 或 CSS 字体 URL
例如 Google Fonts: @import url('https://fonts.googleapis.com/css2?family=Noto+Sans+SC')
使用范围 预设范围（全局/聊天/消息等）或自定义选择器
字体大小 独立调节，支持 px / em 单位
